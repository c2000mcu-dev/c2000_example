# C2833x, C2823x C/C++ Header Files and Peripheral Examples

TI가 제공하는 TMS320C2833x, TMS320C2823x의 C/C++ 헤더 파일/소스들과 주변회로 예제입니다.

[sprc530.zip 다운로드](https://github.com/c2000mcu-dev/c2000_example/raw/refs/heads/main/traningdatab/0001-c2833x-c2823x/sprc530.zip)

압축파일에는 다음 두 파일이 들어 있습니다.

- `DSP2833x_HeaderFiles_QuickStart_Readme.pdf`
- `setup_DSP2833x_v131.exe`

기존 게시물의 설치 안내: 압축을 해제하고 `setup_DSP2833x_v131.exe`를 실행하여 `C:\tidcs\c28\DSP2833x\v131`에 설치합니다.
